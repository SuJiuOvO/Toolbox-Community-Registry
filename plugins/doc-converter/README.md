# 万能文档互转中心 (doc-converter)

> 分类: `document` | 最低客户端版本: `v1.0.0` | 作者: `Toolbox Team`

## 功能简介
支持图片转PPT、PPT转长图/图片、CAD(DXF)矢量转PDF、PPT转PDF、PDF转PPT、Excel转PDF、Markdown转PDF、TXT转Word、Word转PDF、PDF转可编辑Word等各大格式互转。Windows端调用Office/WPS原生引擎实现100%保真导出与Word反向重构；Android端支持调用手机WPS/Office跳转导出并提供详细步骤指引，同时保留离线轻量引擎。

## 平台适配
- `universal`
