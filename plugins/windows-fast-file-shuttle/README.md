# 小文件极速搬运

Windows 原生的小文件复制 / 移动插件。它只把两个目录路径交给原生程序，由程序在内部并行遍历和搬运，不把成千上万个文件路径拼进命令行，也不依赖客户端的内部处理函数。

## 使用

1. 在“源文件夹”处点击 **添加文件夹**，只选一个目录。不要使用“添加文件”。
2. 在“目标文件夹”处点击 **添加文件夹**，只选一个已有目录。
3. 选择移动或复制、冲突策略和线程数。
4. 首次使用可启用 **仅预演**，核对扫描出的文件数与总体积后再关闭并执行。

程序会在目标目录下创建与源目录同名的子目录。例如把 `D:\照片` 移到 `E:\备份`，结果为 `E:\备份\照片`。

## 性能策略

- 使用 Win32 宽字符路径和 `FindFirstFileExW` 的大批量目录枚举，不启动 Shell 或逐项 `cmd` 进程。
- 多线程处理小文件；默认 8 线程，可切换自动、4 或 16 线程。
- 同一卷内移动优先调用文件系统重命名；若目标同名目录不存在，可整目录一次完成。
- 跨卷移动逐文件执行复制，确认目标文件大小正确后才删除对应源文件。
- 保留空目录、文件时间戳以及常规文件属性。
- 不跟随符号链接、目录联接或其他重解析点，避免循环与越界移动。
- 源目录与目标目录相等、互相包含，或单个字段传入多个目录时立即拒绝。
- 源目录不能直接选择盘符根目录（例如 `C:\`），避免误选整盘进行全量扫描或搬运；目标位置可以是盘符根。

## 冲突策略

- **跳过**（默认）：保留目标已有文件。
- **自动重命名**：生成 `文件 (1).ext` 等不冲突名称。
- **覆盖**：替换目标文件。只读属性会被临时清除。

移动操作遇到跳过的冲突文件时，该源文件会保留。若某文件复制或删除失败，程序返回非零退出码并在终端逐项报告，源文件不会在复制失败时被删除。

## 边界

- Windows 的文件系统、磁盘缓存、杀毒软件实时扫描、远端网络盘和 SMall 文件本身的开销仍决定最终速度。本插件减少资源管理器的逐项 Shell 开销，但不会绕过安全软件或硬件限制。
- 跨卷移动不能使用同卷重命名捷径，通常比同卷移动慢。
- 当前不复制 NTFS ACL、备用数据流（ADS）、稀疏文件布局或 EFS 加密属性。普通文档、图片、开发文件不受影响。
- 目标空间不足时操作可能部分完成；失败项会明确列出，源文件仅在对应复制校验成功后才会删除。

## 构建

在插件目录执行：

```powershell
.\build.ps1
```

构建使用 MinGW-w64，并生成 `bin\windows-fast-file-shuttle.exe`。随后在注册中心根目录执行：

```powershell
py -3.12 tools\build_registry.py
```

## 命令行

```text
windows-fast-file-shuttle.exe \
  --source <源文件夹> \
  --target <目标文件夹> \
  --mode move|copy \
  --conflict skip|rename|overwrite \
  --threads 0|4|8|16 \
  [--dry-run]
```

返回码：`0` 全部完成；`2` 有部分文件失败；`3` 用户取消；其他非零值表示参数、路径或运行环境错误。
