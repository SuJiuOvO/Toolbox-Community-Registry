# 图片像素富文本转换 (`image-pixel-richtext`)

这是一个无需修改 Multi-Toolbox 客户端的动态 WASI 插件。它在沙箱内读取图片，按比例缩小到指定最大宽度，再把每个采样像素转换成 Unity / TextMeshPro 风格的颜色标签和 `█` 字符。

## 输出

每张输入图片都会生成一组带输入路径短哈希和本次运行时间戳的文件，避免批量同名文件或重复运行互相覆盖：

- `*_richtext.txt`：主文本，格式为 `<color=#RRGGBB>█`，换行对应像素行。
- `*_preview.txt`：副文本，包含尺寸、可见像素数、透明阈值和不带颜色标签的字符布局。
- `*_preview.png`：彩色像素预览。Alpha 低于阈值的像素输出为透明，其余像素按富文本中的实际 RGB 颜色显示。

客户端当前把输出图片显示在生成文件卡片的缩略图中，点击可打开大图。插件不依赖客户端内置工具 ID，也没有新增客户端硬编码入口。

## 支持格式与安全限制

- 支持 PNG、JPEG、WebP、BMP 和 GIF；GIF 使用首帧，完全离线处理。
- 单文件最大 64 MB；原图单边最大 16,384 像素；解码分配上限 128 MB。
- 输出最大宽度为 1–512 像素（默认 128），且最多生成 262,144 个采样像素，防止极端长图耗尽内存。
- Alpha 小于透明阈值（默认 16）的像素输出为空格。
- 使用最近邻采样，一个输出方块严格对应一个采样像素，适合像素画和字符画。

## 构建

```powershell
rustup target add wasm32-wasip1
.\build.ps1
```

Linux/macOS 可执行 `./build.sh`。构建脚本会把产物复制到 `bin/image_pixel_richtext.wasm`。本地测试可运行 `cargo test`。
