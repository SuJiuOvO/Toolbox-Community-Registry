# 像素富文本工坊 (`image-pixel-richtext`)

一个无需修改 Multi-Toolbox 客户端的动态 WASI 插件，集中提供三种模式：

1. **图片 → 富文本**：批量读取 PNG、JPEG、WebP、BMP、GIF，按最近邻采样转换成 Unity / TextMeshPro 颜色标签和 `█` 方块，并生成字符预览和彩色 PNG。
2. **富文本 → 彩色图片**：解析 `color`、`colour`、`textcolor`、`size`、`line-height`、`br` 等标签，导出可缩放 PNG，支持透明、深色和浅色背景。
3. **富文本像素画**：解析并规范化粘贴的富文本，输出压缩后的主富文本、纯字符布局和彩色 PNG，便于二次编辑与核对。

## 图片转富文本

- 最大宽度为 1–512 像素，默认 128；不会放大小图。
- Alpha 小于透明阈值的像素转换为空格，默认阈值为 16。
- 单文件最大 64 MB；原图单边最大 16,384 像素；解码分配上限 128 MB。
- 输出最多 262,144 个采样像素，文件带路径短哈希和运行时间戳，批量同名文件不会互相覆盖。

## 富文本像素画

- 富文本最大 4 MB；画布单边最大 4,096 像素，最多 1,048,576 个源像素。
- 预览放大倍数可选 1–12；最终单边不超过 8,192 像素，总输出不超过 8,388,608 像素。
- 无法识别的字符、未知标签、错误颜色值或多余的颜色结束标签会给出可读错误。
- 插件只做数据解析和 PNG 编码，不执行输入中的 HTML、脚本或 shell 内容。

## 构建

```powershell
rustup target add wasm32-wasip1
.\build.ps1
```

Linux/macOS 可执行 `./build.sh`。产物写入 `bin/image_pixel_richtext.wasm`；本地测试运行 `cargo test`。
