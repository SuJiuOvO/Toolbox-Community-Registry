# Gemini-Banana 无损去水印模块

> 🍌 针对 Google Gemini、Nano Banana、Imagen 3 系列 AI 生成图片量身打造的**工业级像素还原逆向去水印工具**。  
> 采用确定性代数逆向 Alpha 混合算法（Reverse Alpha Blending），告别任何破坏画面细节的模糊涂抹与 AI 虚构填充。

---

## 🌟 核心技术优势

### 1. 真正的“数学级无损还原”
不同于市面上常见的“画笔涂抹消除”或“生成式 AI 补全（Inpainting）”方案（容易造成局部模糊、边缘晕染或画面细节丢失）：
Google Gemini 生成图片时，右下角的星光角标是通过**标准半透明 Alpha 混合通道**直接叠加在原始渲染图层上的：
$$C_{\text{watermarked}} = \alpha \cdot C_{\text{logo}} + (1 - \alpha) \cdot C_{\text{original}}$$

因为 Google 的白色 Logo 亮度值（$C_{\text{logo}} = 255$）与半透明分布矩阵（$\alpha$）是确定性的，因此可通过精确的逆向代数公式在像素层面 1:1 解算还原：
$$C_{\text{original}} = \frac{C_{\text{watermarked}} - \alpha \cdot C_{\text{logo}}}{1 - \alpha}$$

去水印区域外的像素保持 100% 原始字节不变，水印区域下的像素完美还原原有光影、纹理与细节。

### 2. 智能规格自适应与精准对齐
* **小图规格 (48×48)**：对于宽高任意一边 $\le 1024\text{px}$ 的输出，自动采用 48×48 标定遮罩，对齐右边距 32px、底边距 32px。
* **大图规格 (96×96)**：对于宽高均 $> 1024\text{px}$ 的高分辨率输出（如 2K / 4K / 1K 宽屏），自动采用 96×96 标定遮罩，对齐右边距 64px、底边距 64px。
* **自定义微调模式**：针对特殊分辨率或二次裁剪的图像，支持手动指定水印规格与边距坐标。

### 3. 全平台离线通用
* 纯算法实现，内置预计算 Alpha 遮罩模板，**无需连接任何云端 API 或第三方服务器**，零流量消耗，严格保护个人隐私。
* 支持批量选择图片并行处理，即刻保存至输出目录。

## 💡 使用建议与注意事项
1. **请优先使用原始文件**：逆向解算依赖原始像素值。请尽量使用网页端或应用端“直接下载”的原图。若图片经过第三方聊天软件强力二次有损压缩或手动截图，微小色差可能会影响逆解效果。
2. **数字盲水印说明**：本工具专注去除右下角半透明**可见角标**。DeepMind 的 SynthID 频域隐形水印属于频域载波隐写，不受影响。
