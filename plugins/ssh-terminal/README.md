# SSH 安全终端

需要 Multi-Toolbox 1.1.0 或以上客户端。此插件通过 `ssh_terminal` 宿主交互页面运行，支持 Windows 和 Android。网络由设备直接连接用户指定服务器，不通过中转服务。

## 使用

1. 填写主机名/IP、端口和用户名，不含 ssh:// 前缀。
2. 使用密码认证，或粘贴/导入 PEM / OpenSSH 私钥；加密私钥需填写口令。
3. 首次连接向管理员核对 SHA256 指纹后信任；后续主机密钥变化将拒绝连接。管理员确认更换密钥后，可在已信任服务器管理中移除旧记录并重新核对。
4. 支持标准 xterm-256color 交互 PTY、窗口尺寸同步、Ctrl、Esc、Tab、方向键、复制选中内容、粘贴与字号调节。多行粘贴需额外确认。
5. 连接配置仅保存名称、地址、端口、用户名和认证类型；密码、私钥、口令不写入配置，连接成功后清空输入框。关闭页面即断开。

## 边界

- 当前提供交互终端，尚无 SFTP、端口转发、跳板机和多标签会话。
- 已保存连接配置仍需重新输入认证信息。
- 主机信任记录保存在本机 SharedPreferences，不应通过移除记录绕过未知的密钥变化。
- 私钥格式由 dartssh2 4.1.0 支持范围决定；无效格式或错误口令会在连接前阻止执行。

## 实现与验证

宿主使用 dartssh2 4.1.0 和 xterm 4.0.0，连接/认证/PTY 有独立超时；取消和页面销毁会关闭 TCP、SSH 与 PTY。模型与信任记录测试见客户端 test/ssh_terminal_test.dart。可选本机协议回环测试见 tools/ssh_loopback_server.py 与 test/ssh_loopback_test.dart，测试账号和私钥仅限 127.0.0.1 临时服务器。
