# 摸头 GIF 生成器 (Petpet Generator) v1.2.1

魔性、可爱的摸头（Petpet / Rua）动态 GIF 表情包制作工具。深度对标 [摸头 GIF 生成器 - A.Tools](https://a.tools/zh-cn/Tool.php?Id=500)，基于 Multi-Toolbox 原生纯 Dart 图像管道与 QuickJS 动态沙箱构建。

---

## ✨ 核心特性

- **直通目标分辨率管线 (Zero Downsampling Loss)**：
  - 全新升级 v1.2.1 高保真渲染架构：根据导出尺寸直接动态创建原生高分辨率画布，高清原图直接高保真重采样贴合。彻底告别“先在 112px 画布合成再暴力放大”带来的马赛克与模糊，200px / 256px 大图纤毫毕现！
- **真·透明背景与黑发防穿孔 (True Transparency & Solid Hair)**：
  - 基于客户端底层独家研发的 **Alpha 隔离调色板量化器**，将完全透明通道（Alpha=0）独占索引 0，实体像素聚类至 1~255，彻底攻克人物黑发、深色瞳孔被误判抠成镂空透明斑点的顽疾！
  - 在微信、QQ、Discord 以及系统的深色/暗黑模式下无黑边、无白底，完美融合聊天气泡。
  - 支持关闭透明背景，并自由指定任意 HEX 十六进制底色（如 `#FFFFFF` 纯白、`#000000` 纯黑、`#F0FDF4` 薄荷浅绿等）。
- **双三次插值抗锯齿 (Bicubic Resampling)**：
  - 原生图像管道内置双三次卷积平滑插值（Bicubic Interpolation），摸头手势图层与头像缩放边缘细腻柔和，彻底告别锯齿毛边。
- **完整 A.Tools 参数调节矩阵**：
  - **微调模式**：展开水平与垂直微调滑块（$-30\text{px} \sim +30\text{px}$），精确对齐不同异形发型、高马尾或特殊头型。
  - **翻转控制**：支持**头像水平镜像**与**手势翻转**（小手从右侧探出）双独立开关，自由组合 4 种摸头朝向。
  - **手感全开**：
    - **摸头速度**：$20\text{ms} \sim 150\text{ms}$ 宽幅调节（默认 50ms），数值越小揉捏越欢快。
    - **图片大小**：$50\% \sim 150\%$ 自由缩放被揉捏的头像。
    - **挤压揉捏力度**：$0.0 \sim 2.0$ 范围调节（0.0 仅轻触不变形，1.0 经典回弹，2.0 极限超软超弹）。
  - **多档分辨率**：112px（经典原版）、128px（高清推荐）、160px（大图）、200px（超清）、256px（极致超清表情）。
- **纯本地离线执行**：
  - 所有计算、裁切与动图编码 100% 在本地设备通过宿主纯 Dart 原生引擎完成，无网络请求、零数据泄漏风险。
- **批量并发生成**：
  - 支持单图或多选批量导入，一键导出整套专属摸头表情包。

## 🛠️ 算法原理

基于 5 帧经典受压与弹性复原动力学模型：

| 帧序 (Frame) | 抚摸动作阶段 | 基准尺寸与形变张力 | 视觉效果 |
| :---: | :--- | :--- | :--- |
| **0** | 初始触碰 | $w=98, h=98$ | 小手从上方轻搭头像顶部 |
| **1** | 开始下压 | $w=101, h=85$ | 头顶下压，横向初具弹性微展 |
| **2** | 压至最低 (最大受压) | $w=110, h=76$ | 纵向压扁幅度最大，横向最大展宽 |
| **3** | 弹性反弹 | $w=102, h=84$ | 小手抬起，头像柔和复原 |
| **4** | 抚摸回升 | $w=98, h=98$ | 恢复原始比例，准备下一个循环 |

在每一帧合成中，通过 `Toolbox.image.pipeline` 的内存级图像管线动态构建画布，执行图层叠合、抗锯齿重采样与调色板透明量化，生成无限循环的标准 GIF89a 动态格式。
