# 网易云 NCM 解密 (ncm-audio-converter)

基于纯 Rust 编译的原生跨平台 WebAssembly (WASM) 微内核模块，专为 Multi-Toolbox 设计。毫秒级极速无损解锁网易云专属 `.ncm` 加密音乐，还原为原本的 FLAC 或 MP3 音频文件。

---

## 🌟 核心特性

- **🦀 纯 Rust WebAssembly 微内核**：基于 `wasm32-wasip1` 编译构建，轻量紧凑（~350 KB），零外部 C 库依赖，跨平台（Windows / Android / macOS / Linux）拥有极致统一的高性能表现。
- **🔒 100% 本地离线隐私安全**：所有解密与音频流转均在 WASI 沙箱虚拟文件系统 (VFS) 中闭环完成，绝不上载任何音频与隐私数据。
- **⚡ 毫秒级无损直出，母带音质 0 损耗**：自动探测 NCM 内部包裹的原始音频流（FLAC 或 MP3），直接执行单趟流式解密输出，161MB 巨无霸音频文件亚秒级输出，彻底告别二次重编码带来的音质衰减与漫长等待。
- **🎵 元数据与高清封面完美恢复**：
  - 自动解密内置元数据，精准还原歌曲名、歌手、专辑标签；
  - 提取内嵌高清专辑封面图片；
  - 针对 FLAC 自动注入标准 Vorbis Comment 标签与 Picture Block；
  - 针对 MP3 自动嵌入完整 ID3v2 标签（TIT2, TPE1, TALB, APIC）。
- **📦 智能批量多文件与整目录调度**：结合客户端底座的路径规范化去重与软链防环保护，支持拖拽、多选与整目录扫描，进度实时可视化呈现。

---

## ⚙️ 参数与输入

- **输入支持**: `.ncm`（支持单文件、多文件多选、整目录递归展开）
- **输出格式**: 自动识别并还原为原曲无损音质（`.flac` 或 `.mp3`）
